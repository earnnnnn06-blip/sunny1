# Sunny Glow – Landing Page

Next.js 14 (App Router) · TypeScript · Tailwind CSS · Framer Motion · GSAP ScrollTrigger · Lenis

```bash
npm install
npm run dev     # http://localhost:3000
npm run build && npm start
```

- `app/page.tsx` – all sections, GSAP/Lenis effects (client component)
- `app/Particles.tsx` – floating light particles (canvas)
- `app/globals.css` – design tokens (light/dark), glassmorphism and section styles
- `public/product.jpg` – hero product image (replace with a transparent PNG for a true cut-out)
